# Despacho Jurídico: Lic. Pedro Rosas Cruz

Landing page profesional diseñada para presentar los servicios y la trayectoria del Lic. Pedro Rosas Cruz, especialista en Derecho Constitucional y Amparo.

## ⚖️ Descripción
Este proyecto web sirve como tarjeta de presentación digital para un despacho jurídico, enfocándose en ofrecer una imagen seria, profesional y accesible. La plataforma destaca la experiencia académica del titular y proporciona un punto de contacto inicial para clientes potenciales.

## 🛠️ Tecnologías Implementadas
*   **Estructura:** HTML5
*   **Estilos:** Bootstrap 5.3.2 para un diseño responsive y profesional, junto con CSS personalizado.
*   **Interactividad:** JavaScript para funcionalidades adicionales.

## 📋 Características Principales
*   **Sección de Presentación:** Visualización destacada del nombre del titular y su cédula profesional/especialidad.
*   **Diseño Responsivo:** Implementación con Bootstrap para asegurar una correcta visualización en diferentes dispositivos.
*   **Navegación:** Barra de navegación integrada con diseño *dark theme*.

## 🚀 Cómo visualizar el proyecto
1.  Clona este repositorio.
2.  Abre el archivo `index.html` en cualquier navegador web moderno.
3.  Asegúrate de tener conexión a internet para cargar los CDN de Bootstrap.
